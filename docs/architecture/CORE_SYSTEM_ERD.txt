================================================================================
                          CORE BUSINESS FLOW SUMMARY
================================================================================

                    ┌─────────────────────────────────────────────┐
                    │                 THE FLOW                     │
                    └─────────────────────────────────────────────┘

    1. SALES PHASE
       ─────────────
       Dealer → Customer → Quote (with Building Specs)
                              ↓
                         VP flags for PM if needed (is_pm_flagged)

    2. PROJECT CREATION
       ────────────────
       Quote converts to Project
         • Building specs transfer
         • PM flag → is_pm_job
         • Director assigns PM (assigned_pm_id)

    3. PRODUCTION PHASE
       ────────────────
       Project → Modules
         • Modules flow through 12 stations
         • Workers perform QC at each station
         • queue_position tracks line flow

    4. TRACKING
       ────────────────
       • Tasks track PM workflow (19 workflow stations)
       • Purchase Orders track procurement
       • Worker Shifts track labor
